# 浏览器 0.3.1

图片解析修复由 HIOS 主程序提供，需使用包含该修复的 Tauri 开发版并重启；仅升级此插件不会改变旧版主程序的解析能力。

需要 HIOS Next 3.4.7 或更高版本；3.4.6 及以前不支持。Windows / Tauri WebView2 优先，Electron 不再提供重排网页降级。

- 节点直接承载真实网页，保留地址栏、后退、前进和刷新，不弹独立窗口。
- 无全页扫描、原图库或自动下载；悬停图片才识别候选，点击＋或拖到画布才下载。
- 优先使用页面明确提供的原图、高清链接或 srcset；若不可用则尝试网页显示的图片并标注未确认原图，不猜测通用 CDN 原图地址。
- 沿用网页 Cookie/Referer 下载，检查格式、大小和像素尺寸，原字节入素材库，不截图、不转码。网站声称的原图地址仍不能证明其为相机原文件。
- 页面被其他节点/面板遮挡或部分移出窗口时暂时隐藏原生视图，稳定可见后恢复；这是 WebView2 原生视图层级的保守处理，不是网页重载。
- 普通新标签链接在节点内打开，脚本弹窗被拒绝。

尚需真实站点、登录态、多节点遮挡和跨 WebView2 拖放完整回归。

开发验证：TypeScript、前端生产构建、13 项 Node 回归、2 项 Rust 浏览节点测试及插件清单校验通过。隔离 WebView2 已验证点击加入、带 Cookie/Referer 的原字节下载与素材入库；原生跨 WebView 拖放仍待手动验收。跨域 iframe 内图片暂不支持。
