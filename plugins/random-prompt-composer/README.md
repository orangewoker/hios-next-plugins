# 随机组合提示词

独立 HIOS 插件，版本 0.1.2。无需 Python、Embedding、LM Studio 或 API Key。保留原 K2 人像提示词生成器，不改变它的行为。

## 安装与连线

1. HIOS「插件管理」粘贴安装地址：`https://github.com/orangewoker/hios-next-plugins/tree/main/plugins/random-prompt-composer`。国内用户可在 HIOS 设置中选择 Gitee 渠道，宿主自动使用官方镜像；安装后从同一来源检查更新。也可从本地目录安装本文件夹 `plugins/random-prompt-composer`，但在线更新请使用仓库地址安装。
2. 添加画布节点「随机组合提示词」。七类各抽一条，组成一个人的完整造型。
3. 将唯一输出「正向提示词」连接到 LLM 节点的文本输入。
4. 点击「复制 LLM 深化系统提示词」，粘贴到 LLM 的**系统提示词栏**。画布节点只显示复制按钮；应用中可另外查看全文。这不是普通连线输入；不需要修改 HIOS 主程序。
5. LLM 输出再接图像生成节点的提示词输入。建议 LLM 温度先设为 0.4—0.7，关闭表格输出；不要启用与此格式冲突的 Skill。

```text
文本（可选补充要求） → 随机组合提示词 → LLM → 图像生成
                                       ↑
                            手动粘贴深化系统提示词
```

## 操作语义

- 人物定位描述、上衣、下衣、鞋子、发型、姿势、镜头：各 300 条，总计 2100 条；不将旧备份、1000 条模块库与最新版标签库混用。
- 七类标签作为整体默认收起，点击展开后可选择与锁定。下拉菜单跟随 HIOS 深浅及自定义主题，支持搜索编号/关键词，以及方向键、Enter 选择和 Escape 关闭。
- 手动选择某项会自动锁定；取消该项锁定后才重新参与随机。锁定项始终保留。
- 种子 0：每次抽取用浏览器加密随机源生成新种子；非零整数（最大 4294967295）复现抽取。界面显示上次种子，可填回以复现；锁定项与补充要求也要一致。
- 「随机未锁定项」只改变预览、不输出；插件内部「运行并输出」输出当前预览，不重复抽取。
- HIOS 外壳运行按钮、执行下游或整张画布时：默认先重新随机再输出；关闭「运行时重新随机」后复用当前选择。
- 补充要求可手填，也可接上游文本；两者同时存在时依次合并，不让上游自动覆盖本地文本。更改上游会刷新预览。
- 每个节点由 HIOS 独立保存种子、锁定、选项和补充要求；不使用跨节点全局 localStorage。应用页面是独立试组合工具，设置不会暗中同步到画布节点。
- 文本端口只包含所选标签和补充要求，不含系统提示词、素材编号、随机种子或解释。
- 抽取本身不做语义检索或自动换装。物理冲突交由 LLM 按系统提示词最小调整；未调用真实模型进行效果评估。

## 资料与维护

`data/library.mjs` 从用户提供的 `Krea2_七类标签库_300` 原样导入，包含各源文件 SHA-256 和条目 ID。运行时不依赖桌面原始路径。插件独立发布，不打包进桌面主程序。

显式重新导入：

```powershell
node scripts/import-random-prompt-library.mjs '<Krea2_七类标签库_300的绝对路径>'
```

深化系统提示词的唯一代码来源为 `runtime/core.mjs` 的 `SYSTEM_PROMPT`，同内容另存为 `LLM深化系统提示词.txt` 供直接复制。

验证（项目根目录）：

```powershell
node --test tests/random-prompt-composer.test.mjs
node_modules/.bin/electron.cmd tests/random-prompt-composer-ui.cjs
node scripts/check-plugin-ui.mjs
```
