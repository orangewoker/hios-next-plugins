## 0.3.0 人像与参考图追色

- 人像精修统一放在一个折叠板块，启用后本地 MediaPipe Face Landmarker 478 点检测，最多 4 张脸，按从左到右编号；宽图使用重叠分块补检。
- 点击选人或编号切换，每人独立保存参数。皮肤修饰、五官调整、局部颜色各自开关。
- 磨皮为 GPU 边缘保留平滑与纹理混合，不重建人脸；结合皮肤蒙版，保护眼睛、眉毛、嘴唇。支持肤色均匀、提亮、肤色/唇色着色和亮色口腔区域牙齿美白。
- 瘦脸、下巴长度、眼睛大小、鼻翼宽度、嘴唇大小均以零为中性值；侧脸、遮挡与远景需检查效果。
- 手动液化：推拉、膨胀、收缩、局部恢复；逐帧预览，一笔一撤销，保留最近 32 个控制点。大幅变形不保证背景直线不弯曲。
- 参考图追色：标准 Lab 均值/方差匹配，可选整体或皮肤，强度可调；只保存统计值，不把参考图片塞进节点状态。重新打开后更改匹配区域需重选参考图。
- 人像与追色要求 WebGL2。预览和全尺寸 PNG 输出共用 shader。五官辅助点只在编辑器显示，不进入导出；图片/皮肤/深度在同一变形坐标取样。
- 自定义预设保存当前人脸的修饰参数，不保存特定人脸位置、手动液化或参考图统计。更换原图清除图像专属编辑。
- 实现为独立编写，未复制 Pixel Cake 的 UNLICENSED 源码。没有加入 GPEN 换细节式增强、AI 自动祛痘、RAW 或 16bit 导出。

## 使用

- 节点接入图片，选预设/调参数，点击 HIOS 原有运行按钮输出原尺寸 PNG；展开编辑后返回画布运行。
- 图片上的白色对比线有圆形手柄，直接拖动；支持方向键、Home/End 和底部分界滑块。
- GPU 预览随滑块逐帧更新，预览不触发下游执行。
- 应用入口打开图片，点击「输出图片」交给宿主。浏览器独立调试时下载 PNG。
- 放大图片后可以拖动平移，「适应」恢复完整构图。
- 白平衡取样：点击应为中性灰/白的区域做有界纠偏；Esc 退出工具。
- 自适应纠偏默认关闭：低饱和中间调候选校正色温/色调，有限提升低对比度并收敛过艳。不承诺物理原色恢复，夕阳等场景需自行判断。

## 肤色

默认使用本地 MediaPipe 六分类人像模型，合并身体皮肤与脸部类别，不是把木头/墙面等所有橙色都调白。

- 开启肤色或应用人像预设后首次分析。
- 「查看影响范围」显示洋红蒙版，不进入导出。
- 「补选 / 擦除」在图片上涂抹，松开后更新，可撤销；Esc 退出。
- 人像模型不能保证所有风格、多人、遮挡和远景都准确，可手工修正或显式切换颜色范围。AI 失败不会悄悄回退全图选色。
- 更换原图时清除上一张图的手工修正与对焦位置；同图重开保留。

## 景深

启用后本地 Depth Anything V2 Small q8 估计相对逆深度。

- 点击「点击对焦」后在图上选点，使用邻域中位深度降低误差。
- 虚拟光圈 f/1.4–f/16、虚化强度、清晰范围、前景虚化、主体边缘保护。
- 「查看深度」中白色较近、黑色较远，仅影响预览。
- 使用 48 点圆盘采样、线性光混合、近景遮挡抑制和主体边缘权重，不是简单背景高斯模糊。
- 皮肤与深度使用本地图像哈希缓存（最多 8 张），调整参数不重新推理。首次分析需要等待，失败可重试。
- 不能恢复原图已有模糊，不等同真实相机焦距/距离标定。细发丝、透明物、细杆和大光圈仍可能有轮廓误差；可提高光圈值或降低强度。

## 预设与状态

- 内置保暖净肤、清透冷白、自然肤色、去暖黄、去红偏、去灰、过艳收敛、自然中性、植被自然。
- 自定义预设保存调色开关、参数、强度和自适应规则；不保存原图、蒙版笔迹、景深或对焦坐标。
- 同源 localStorage 尽力共享预设，节点状态保存副本，不同安装来源可用 JSON 迁移。
- 折叠不关闭效果，关闭模块保留参数，双击滑块重置参数。参数自动保存，结果只在运行时发布。

## 实现与限制

- GPU shared/gpu.mjs 两个 shader pass，预览与导出共享运算。无 WebGL2 时 CPU Worker 支持调色，景深明确报需硬件加速。
- GPU 预览最长边 1280，CPU 640。导出原尺寸，上限 2400 万像素、64 MB 及显卡纹理上限。
- Canvas 解码至 sRGB，不保留 EXIF/ICC/HDR。未实现专业曲线编辑、参考图匹配、LUT 导入或生成式背景补洞。
- analysis.mjs 管理模型/缓存；depth-worker.mjs 独立推理；皮肤模型仅在首次分析时运行。
- 深度缓存不塞入节点 state，笔迹数量与坐标精度有上限。
