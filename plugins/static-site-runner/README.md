# 静态网页

HIOS Next 独立画布插件。每个“静态网页”插件节点都能选择并运行自己的本地网页目录。

## 0.2.0

- 改为完全独立的 `rendererEntry` 插件，通过主程序开放的通用目录接口选择文件夹。
- 界面、入口选择与运行状态均由 GitHub 插件自身维护。

## 功能

- 指定一个本地静态网页目录。
- 自动识别 `index.html`，也可在目录含多个 HTML 时切换入口。
- 点击“运行”启动或刷新网页。
- 同时创建多个窗口，分别运行不同目录。
- 窗口支持拖动、缩放、恢复默认大小和最大化。
- HTML、CSS、JavaScript、图片、字体、音视频和 WASM 等资源均从本地目录加载。

## 要求

需要支持 `static-site-runner` 内置运行时的 HIOS Next 版本。
