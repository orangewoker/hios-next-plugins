图库设置

已下载图库会自动识别，插件更新不会下载素材。缺少图库时请到插件管理单独下载。也可选择自己的仓库根目录或 library 目录替代，只读使用，不复制整个图库。

也可以从下拉列表重新使用已授权的目录。关联成功后点击「应用选择」保存到当前节点。
