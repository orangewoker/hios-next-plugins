# 网页账号代理

本插件需要包含网页账号宿主适配的 HIOS Next、Windows 和 Microsoft Edge，不需要 API Key 或额外网关。旧版 HIOS 即使安装插件，也不具备路由执行能力。

1. 安装并启用「网页账号代理」，在「应用」打开它，或在「插件管理 → 网页账号代理」点击「设置账号」。不需要创建画布节点。
2. 选择 Muse、Gemini 或 Google Flow，输入备注，点击「添加账号并登录」；在打开的独立 Edge 窗口手动登录。
3. 登录完成后，手动关闭该登录窗口，HIOS 会在后台通过该账号发送一条随机校验码提示（Google Flow 则进入已打开的专用项目）。验证通过后，设置 → AI 路由会出现「渠道 · 备注」，可用的网页路由入口自动激活。关闭设置页不影响已注册路由。
4. 重新登录请使用原账号条目，保留相同路由。另一账号使用另一条目和浏览器配置。路由请求发现登录失效或账号变化时会停用路由；重新验证即可恢复。

- Muse：提供默认对话、文生图与文生/图生视频（`muse-video` 支持单张参考图）。
- Gemini：可点击「刷新模型」读取网页对话模式与生图工具选项，并提供默认文生图。刷新不提交生成，网页默认入口不承诺具体版本或额度。
- Google Flow：提供项目内文生图与文生视频入口；登录时请先打开专用项目后再关闭窗口。
- 比例和时长会作为要求发给网页，实际结果由网站决定。任务异常不自动换号重发。

网页登录可能因平台地区、权限、验证要求或页面更新失败；没有通过实际验证的账号不会新增路由。

浏览器登录状态由本机 Edge 的独立配置目录保存。HIOS 不读取或迁移密码、Cookie，不将它们用作 API Key。断开路由不会清除 Edge 中的网页登录状态。
