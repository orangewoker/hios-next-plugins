# K2 人像提示词生成器

版本：`0.2.3`

## 使用方式

1. 从 HIOS Next 的应用列表打开 **K2 人像提示词生成器**。
2. 在完整应用中选择参数；设置变化时会自动生成并保存最新提示词，也可使用“全部随机”或“生成提示词”。
3. 在画布中添加 **K2 人像提示词**节点。
4. 节点会自动读取应用保存的设置和最新提示词；点击“应用随机”会让完整应用在后台随机一次（不离开画布）并自动同步；点击“运行并输出”或运行画布时，将文本从唯一的“提示词”输出端口发送到下游节点。

画布节点不再维护独立参数，避免应用设置与节点设置不一致。节点中的“打开应用设置”用于返回完整编辑器，“同步设置”用于立即刷新预览。

## 安装

在 HIOS Next 的“插件管理 → 安装插件”中使用：

`https://github.com/orangewoker/hios-next-plugins/tree/main/plugins/k2-prompt-generator`
