# K2 人像提示词生成器

HIOS Next 插件版 K2 人像提示词生成器。

## 入口

- 应用：完整参数编辑器，支持随机、锁定、年龄联动、SFW/国际版、复制和自检。
- 画布节点：紧凑版常用参数面板，只输出一个 `prompt` 文本端口；点击运行时随机生成并发送提示词，可打开完整应用继续编辑。

## 说明

词库和生成逻辑来自用户提供的 HTML，已移除原来的 XOR/Base64 混淆包装，方便在插件中维护。插件不需要网络、文件系统或外部 API。

## 本地安装

在 HIOS Next 的「设置 → 插件」中选择「安装本地插件」，选择本目录后即可在「应用」页和画布节点菜单中使用。
