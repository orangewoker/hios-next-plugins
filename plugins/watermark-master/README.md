# 水印大师

HIOS Next 第三方画布插件。在本地为图片添加文字水印或图片水印，不上传原图。

## 功能

- 单图片输入、单图片输出
- 文字水印：字体、字号、粗斜体、横排/竖排、对齐、行高、字距、颜色、背景、透明度与旋转
- 图片水印：从本地选择 PNG/JPG/WebP/SVG，设置尺寸、透明度、旋转和位置
- 九宫格定位、像素/百分比单位、单个/平铺
- PNG、JPG、WebP 输出，全分辨率渲染
- 自动适配 HIOS 深浅主题

## 安装

在 HIOS Next 的“插件管理 → 安装第三方插件”中粘贴：

```text
https://github.com/orangewoker/hios-next-plugins/tree/main/plugins/watermark-master
```
