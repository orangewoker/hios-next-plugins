# 晨羽智云 · HIOS Next 插件

独立的应用工作流插件，使用晨羽开放 API。无需修改 HIOS 主程序，也不依赖晨羽网页 Cookie。

## 安装与使用

1. 在 HIOS 的插件管理中粘贴下方安装 URL；也可选择**安装本地插件**，选取含 `plugin.json` 的目录（ZIP 先解压）。
2. 从“应用”打开“晨羽智云”。
3. 在“连接设置”输入自己的 API Key 并保存。插件不附带测试凭据。
4. 选择工作流、输入参数与素材后运行。
5. 在画布使用已有的**应用工作流**节点，来源选择“晨羽智云”，再选择工作流。图片、提示词会按参数定义映射，结果通过统一输出口回传。

已内置且锁定发布版本：

| 工作流 | 输入 |
|---|---|
| SeedVR2 放大 | 图片、短边尺寸（官方默认 2560） |
| Qwen Image2.1 图像编辑 | 提示词、8 种宽高比、百万像素、1–8 张参考图 |

当前 HIOS Next 4.6.5 已具备需要的应用工作流通道，安装此插件无需更新主程序。

## 添加其他工作流

- 在工作流管理粘贴官方页面的“复制文档”内容，或导入包含 `editable_parameter_manifest` 的详情 JSON。
- 也可编辑插件自身导出的 JSON：点击某个工作流的“编辑配置”，修改字段后重新导入。
- 两个内置工作流支持直接粘贴工作流 ID / 官方 API 页面链接。其他链接需要补充文档或 JSON，**不会虚构读取参数的开放接口**。
- 官方复制的 Markdown 不含完整枚举、范围、媒体角色等信息。复杂参数应使用 JSON 补充，导入后检查表单。
- 导入文档时，需要补全参考报价，并核实“不涉及外部模型费用”。风险未知或涉及外部模型的工作流默认不能自动运行。
- `revisionId` 必须填写，避免工作流更新后默默改变输入、输出及报价。锁定版本不等于锁定最终费用。

文档和 JSON 都只作为数据解析，不会执行其中的 curl、脚本或其他指令。

## 费用

**参考报价 ≠ 最终扣费。**

设置中的“单次参考报价门槛”只检查本地保存的参考报价。当前文档没有提供服务端预算硬上限参数，因此插件不宣称能保证实际扣费不超过该值。

任务记录分别显示：

- `quote_amount`：提交时参考报价 / 预冻结金额；
- `final_amount`：最终结算金额；
- `settlement_status`：是否已结算。

不把 `compute_cost`、`total_cost` 或内部执行任务 ID 当作用户最终账单或查询订单 ID。

## 素材与输出

- 支持 HTTPS URL、data URL、`asset://`，以及 `{ uri, role }` 媒体对象。
- 本地图片、视频、音频和文件先使用 multipart 上传为临时素材，单文件最大 100 MB。
- 临时素材默认 48 小时过期；任务返回的结果应及时保存。
- 使用输出 manifest 判断媒体类型，不依赖 URL 扩展名；支持多个结果。
- 任务执行成功后如仍待审核，继续查询，不提前返回空结果。

## 任务恢复与停止

- 提交前保存原始请求及 `idempotency_key`。
- 网络异常导致提交结果不确定时，保留记录，禁止用新键自动重复提交。
- “用原幂等键恢复提交”由用户主动触发，重放原请求，避免重复生成与扣费。
- 已有 `run_order_id` 的记录只查询该订单，不重提。
- “停止等待”只停止本地请求和轮询，不代表取消云端任务。
- 失败不会自动重跑；显存不足时显示针对性提示。

## 凭据

默认只在当前窗口的会话存储保留 Key。勾选“在此设备记住 Key”后存入插件本地存储，**不是系统加密密钥库**。

Key 不写进插件清单、源码、宿主项目状态或任务记录；错误信息会隐藏当前 Key。清除按钮同时删除会话及本地保存值。
