# 晨羽智云 0.1.0 发布验证

日期：2026-11-17。公开包不包含 API Key、账号信息、测试订单标识、用户照片或生成素材。

## 接口验证

- 使用经授权的测试素材，验证 Bearer 鉴权、multipart 临时素材上传、固定版本提交及订单查询。
- Qwen Image2.1 图像编辑完成了提交、运行、审核和图片下载链路。
- SeedVR2 的测试遇到云端显存不足；正确识别失败，不自动重复提交。
- 参考报价与最终结算可能不同，两者分开显示；没有服务端预算硬上限接口，不宣称本地报价门槛能保证最终扣费。

## 回归范围

- 插件独立测试：参数定义、文档导入、精确金额计算、媒体与 multipart、鉴权与脱敏。
- 提交前持久化、原幂等键恢复、禁止不确定状态下自动重提。
- 有界查询重试、审核等待、停止本地等待与任务记录恢复。
- Key 不进入宿主项目状态，历史合并不丢失未完成订单。
- 宿主侧另验证插件发现、输入映射、清单/入口、本地素材转换与 UI SDK；定向 34 项及 TypeScript 检查通过，不代表宿主全量回归结论。
- 浏览器离线夹具验证了目录读取、隐藏工作流运行、进度事件、结果回传、应用内表单与深浅色主题；离线请求均模拟。

当前 HIOS Next 4.6.5 具有所需通用接口，此插件不要求额外的主程序更新。未声称已完成用户安装版的原生端到端验收。
