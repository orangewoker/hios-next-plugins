# 拼图

HIOS Next 画布插件：把 2、4、6 或 9 张图片合成为宫格拼图，并支持自定义间隔与文字水印。

## 功能

- 双图、四宫格、六宫格（3 列 × 2 行）、九宫格（3 × 3）
- 左侧只有一个多图片输入口，图片按连线建立顺序排列
- 可直接拖动预览中的编号区域，交换图片位置
- 间隔大小 `0–200px`，默认 `1px`
- 间隔颜色自定义，默认白色
- 水印添加到每个小图或最终拼图
- 水印文字、位置、颜色、透明度、字号可调
- 图片保持比例，不裁剪；输出 PNG 图片

## 安装

在 HIOS Next 的插件管理中安装：

`https://github.com/orangewoker/hios-next-plugins/tree/main/plugins/puzzle-grid`

安装后，在画布节点菜单中选择“拼图”，把图片节点依次连接到同一个输入口并运行即可。布局、水印等菜单使用插件内弹层，会从点击处展开并跟随节点。
