# DLSS 5 图片增强

需要 HIOS Next 桌面版 **2.6.3 或更新版本**。在“插件管理”中安装 `https://github.com/orangewoker/hios-next-plugins/tree/main/plugins/dlss5-image`，以后可在插件管理中在线更新。

HIOS 图片增强应用和画布节点共用本地图片处理链。需自行安装 [Visual Enhancer](https://github.com/Merserk/dlss5-visual-enhancer)，在应用中选择 `VE_CLI.exe`。运行库不随 HIOS 分发。

目前仅支持 Windows、NVIDIA GPU 和 PNG/JPG/WEBP 输入。画布节点从画布连线读取图片素材地址，支持 HIOS 本地素材、图片 data URL 和 HTTP(S) 图片。运行后会在右侧生成独立图片节点，插件节点本身不预览结果。应用页和节点均可调节自然／默认／电影感风格与 0–2 的增强强度。失败时返回运行库原始错误，不静默回退到其他增强器。

v0.1.3 新增“光影材质增强”模式：Visual Enhancer 完成原有神经增强后，插件在结果上加强已有阴影层次、受光面、材质细节和高光反射。四项效果均可独立调节；选“基础增强”可保持旧版输出。画布节点会把最终图片保存为 HIOS 素材并生成图片节点；应用页显示基础与最终图片对比，基础图片由现有接口保存到素材库，最终图片提供下载按钮。画布节点输出的最终图片以 PNG 为优先格式，超过消息大小限制时尝试 WebP。该模式最多处理 2400 万像素。

v0.1.4 将应用页和画布节点的下拉菜单、滑块改为插件自身渲染的主题控件，接收 HIOS 的背景、文字、边框和强调色，并随浅色／深色主题切换。下拉菜单保留键盘操作；处理参数和输出流程不变。

这是实验性图片增强工作流，并不等同于游戏内 NVIDIA DLSS 5 的 3D 引导渲染。插件模式不能生成原图不存在的准确投影或镜面内容。默认采用 CLI 自身的保守设置，不开启高倍放大。视频支持留待后续版本。
