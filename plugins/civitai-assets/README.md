# Civitai 素材库

在 HIOS Next 独立插件节点中搜索、预览 Civitai 图片，并从图片输出端口交给其他画布节点。

## 0.4.1

- 移除顶部“下一页”，改为图片列表底部“加载更多”。
- 新结果会累计追加到当前列表，不再替换已经浏览的图片。
- 底部同步显示累计张数、页数和是否还有更多结果。

## 0.4.0

- 图片可单击多选，右下角可将所选原图批量输出到画布。
- 图片右键菜单新增“保存原图到画布”，输出后自动创建图片节点并连接插件输出端口。
- 设置面板支持自定义 Civitai API 地址、API Key 和 HTTP(S) 代理。
- API 请求改用宿主通用网络接口，避免浏览器 CORS 限制并让代理配置真正生效。

## 0.3.0

- 改为完全独立的 `rendererEntry` 插件，搜索界面和 Civitai API 逻辑随 GitHub 插件更新。
- 不再依赖主程序中的 `civitai-assets` 专用渲染分支。

安装 URL：`https://github.com/orangewoker/hios-next-plugins/tree/main/plugins/civitai-assets`
## 0.5.0

- 缩略图改为等比完整显示，默认不裁切、不拉伸图片。
- “加载更多”固定按每批 30 张追加到当前列表，并兼容 API 返回的 nextPage 地址。

## 0.5.1

- 加载下一批图片时保持插件内部滚动区域，不会因为追加内容把节点整体拉长。
- 追加完成后保留当前滚动位置，向下滚动即可查看新增图片。
