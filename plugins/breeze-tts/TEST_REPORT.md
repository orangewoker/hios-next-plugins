## 真实 HIOS sidecar 回归

执行 `node scripts/verify-breeze-sidecar.mjs`，不使用假的 main IPC 或假的 LocalDataStore：

1. 独立临时数据根目录启动本仓库打包后的真实 sidecar。
2. 通过真实 IPC 安装 Breeze 目录、查询 runtime 注册、保存本机端口，启动真正的工坊子进程并读取管理状态。
3. 禁用插件后确认监听端口关闭。
4. 保存远程连接，通过真实 Windows DPAPI 加密落盘；启动全新 sidecar 后从磁盘解密成功，非读取内存缓存。
5. 远程合成测试音，通过真实 `LocalDataStore.importAssetBytes` 保存为音频，再通过真实 HIOS asset 协议读回 WAV 并校验头和大小。
6. 确认远程管理被拒绝；覆盖本地安装与卸载会停止服务。
7. 宿主进程退出、IPC 断开后确认子服务退出，不遗留监听端口。

测试自动清理自己的临时文件，不触及用户现有 HIOS 数据。

## 浏览器验证

### 应用主题与复制修正

- 文件选择改为主题化按钮和文件名显示，保留原文件 input/accept/File 数据链路；应用与节点共用，不再显示系统灰色选择按钮。
- 单选、复选、滑杆、下载进度、占位文字和 iframe 文档/内部滚动条统一使用宿主主题变量；移除数字输入框的系统灰色步进按钮，键盘增减不变。
- CUA 实测森林深绿、浅色、深色主题；检查语音创作、音色库、模型与服务及设置页面。
- 剪贴板夹具使用真实 BreezeFrameBridge，并通过 iframe `allow="clipboard-write 'none'"` 禁止内嵌页直接复制；点击按钮后宿主复制分支完成、页面显示中文成功状态。夹具只使用测试密钥，不读取用户服务密钥；浏览器工具的虚拟剪贴板不等同于原生系统剪贴板，未据此宣称已完成打包 WebView2 系统剪贴板读回。
- 自动复制失败时显示并选中手动复制字段，离开设置页清空；单元测试覆盖权限拒绝、无安全上下文、DOM 回退失败、空密钥、关闭页面时迟到写入和不回传密钥。

本轮使用 Codex 内置浏览器 / CUA：

- 新的紧凑应用导航、设置面板与节点布局；旧版宣传大标题、侧栏、装饰波形已移除。
- 节点展开合成模式下拉：实际 DOM listbox，深色背景、紫色宿主强调色选中；键盘 ArrowDown、Home、Enter 选择正确，切换克隆模式与参考输入同步。
- 宿主 theme 消息实时切换浅色/深色；不依赖原生系统弹出菜单。
- 托管应用设置展示本机端口和局域网开关，本机密钥/地址不需要手工填写。
- 节点接受宿主运行指令，返回 runId 与音频/文本/信息/时长四端口；音频输出是 canonical `hios-asset:`，不通过 base64 传输。
- 取消慢任务后仅返回当前 runId 的取消结果，不重发旧音频。
- 隐藏工作流列出全部生成参数，运行返回音频素材 URL 与正文，没有交互式应用输出。
- 原独立服务与节点预览均刷新到新版界面。此前 0.1.0 阶段还验证过真实 WLAN 地址、独立浏览器上下文、390 px 视口、远程无管理权限、HTTP 非安全上下文降级和试听/下载。

浏览器中的托管协议测试夹具不注册 HIOS 原生资源 scheme，因此该夹具的 `hios-asset:` 播放器不能直接播放。资源持久化与协议读回由上面的真实 sidecar 回归验证；不将普通 HTTP 夹具冒充已打包 WebView2。
